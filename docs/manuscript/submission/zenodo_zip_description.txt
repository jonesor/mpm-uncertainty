Zenodo archive description
==========================

Archive file
------------
- Filename: mpm-uncertainty_zenodo_20261118_122531.zip
- Purpose: Reproducible snapshot of data, code, models, and manuscript sources/outputs used in the paper:
  Jones, O. R. and Simmonds, E. G. (2026) When does sampling uncertainty matter in matrix population models? Evidence from published projection matrices. Methods in Ecology and Evolution.

What the zip contains
---------------------
Top-level project folders included in the archive:
- code/                  Reusable R helper functions.
- data/                  Raw, derived, and metadata files used by the analyses.
- docs/                  Manuscript source files and analysis documentation.
- figures/               Figure outputs generated by scripts.
- models/                Stan model files.
- scripts/               End-to-end analysis scripts (S01-S16).

Top-level files included in the archive:
- README.md              Repository overview and run order.
- MANIFEST.md / .csv     File list with sizes and MD5 checksums.
- RUN_REPRODUCTION.R     Script that runs the analyses and renders the manuscript files.
- .lintr                 Lint configuration.

Reproducibility notes
---------------------
1) Open the project in R/RStudio from the extracted archive root.
   Note: only small summary caches (data/derived/analysis_cache/*.csv) are archived; large intermediate .RData caches are regenerated by the scripts. Raw PRISM rasters (about 2.8 GB) are not archived; extracted climate values are in data/derived/climate/.
2) Run scripts in order (S01 to S16) for full regeneration of analysis outputs, or source RUN_REPRODUCTION.R.
3) Render manuscript files via:
   source("docs/manuscript/render_manuscripts.R")
4) This command renders the main manuscript and supplement (and rebuilds a Zenodo staging bundle, which is not needed for reproducing the paper).

Data provenance
---------------
- Matrix data from COMPADRE and associated study-level sources.
- Climate covariates from PRISM (downloaded by project scripts where required).
- Provenance and source notes are documented in data/metadata/.
