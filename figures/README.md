figures/
--------
Generated figures for the manuscript. These are created by scripts in `scripts/`.

Structure
---------
- Root `figures/`: figures directly referenced in manuscript Rmd files.
- `figures/analysis_diagnostics/`: additional script outputs for checks, diagnostics, and exploratory comparisons.
- `figures/archive_legacy/`: superseded legacy outputs retained for traceability.

Notes
-----
Run the scripts in `scripts/` to regenerate figures; filenames are defined in each script.
